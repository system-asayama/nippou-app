1. Google Cloud で登録するコールバック URL

Google Cloud の「承認済みのリダイレクト URI」に、次の URL をそのまま登録してください。

手順: Google Cloud コンソール →「API とサービス」→ Calendar API を有効化 →「OAuth 同意画面」を設定 → 「認証情報」→「OAuth クライアント ID」（ウェブアプリケーション）を作成し、上の URL を登録します。

2. クライアント ID とシークレットを登録

暗号化して保存され、画面には表示されません。

自動判定がうまくいかない場合（プロキシ配下など）だけ、Google に登録したものと同じ URL を入力してください。
