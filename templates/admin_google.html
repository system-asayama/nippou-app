ここで登録するのは「このアプリを Google に登録するための ID」で、会社全体で 1 つだけ必要です。 登録が済むと、利用者は各自が「カレンダー」から自分の Google アカウントを連携できるようになります （利用者ごとの登録作業はここでは不要です）。

{% if source == "env" %}

現在はサーバーの環境変数の設定が使われています。下のフォームで登録すると、そちらが優先されます。

{% endif %}

1. Google Cloud で登録するコールバック URL

Google Cloud の「承認済みのリダイレクト URI」に、次の URL をそのまま登録してください。

2. Google Cloud での作業（別タブで開きます）

  1. プロジェクトを作成（既にあればそのまま次へ）
  2. Google Calendar API を有効化
  3. OAuth 同意画面を設定 （Google Workspace なら「内部」、それ以外は「外部」＋利用者をテストユーザーに追加）
  4. 認証情報 → OAuth クライアント ID を作成 （種類は「ウェブアプリケーション」。「承認済みのリダイレクト URI」に上のコールバック URL を貼る）
  5. 発行されたクライアント IDとクライアントシークレットを、下の欄に貼って保存

3. クライアント ID とシークレットを登録

暗号化して保存され、画面には表示されません。

自動判定がうまくいかない場合（プロキシ配下など）だけ、Google に登録したものと同じ URL を入力してください。

{% endif %}

⚠️ クライアント ID を別のものに変更すると、既に連携済みの利用者は連携が無効になり、各自での再連携が必要になります。
